## Dataset

This project uses the EuroSAT dataset created by Patrick Helber,
Benjamin Bischke, Andreas Dengel, and Damian Borth.

Dataset:
https://doi.org/10.5281/zenodo.7711810

The EuroSAT dataset is distributed under the MIT License and is
based on Copernicus Sentinel-2 satellite data.
